layers Text Layers Demo token-based coordinates How it works

A text layer annotates portions of a base text with fragments. Each fragment has a location with token-based coordinates, where a token is any sequence of non-whitespace characters. A point is Y.X@AxR:

  • Y: the line number (1-N).
  • X: the token number in the line (1-N).
  • optionally, when not selecting whole tokens: A is the first character in the token (1-N), and R the count of characters (omitted when 1).

A selection spanning several tokens has a start and an end point separated by -: the start point picks from its A to the end of its token, the end point picks the first R characters of its token. Whitespace at the edges of a selection is ignored. For instance, with the default text: 2.1 is gamma, 1.2@2x2 is et, 3.1@4x2-3.2@1 is ta e.

Fragments in the same layer never overlap: so their characters are highlighted and blocked, and a selection always stops before them. Click a fragment to pick it; select any other portion of text (by dragging, SHIFT+clicking, or with SHIFT+arrows) to get its location, and add it as a new fragment. You can also type coordinates in the box below the text to select them.
